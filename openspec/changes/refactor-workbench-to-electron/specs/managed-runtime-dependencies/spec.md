# managed-runtime-dependencies

## Purpose

为桌面实验平台明确可随应用提供的运行环境、需要官方准备的外部工具和必须人工完成的系统授权，使实验者可离线使用核心功能，并能根据各能力的真实依赖状态准备真机与正式采集环境。

## ADDED Requirements

### Requirement: 无全局工具的核心离线运行
首版桌面制品 SHALL 在目标 Windows 11 x64 和 Ubuntu 24.04 LTS x64 原生桌面上，支持没有全局 uv、Python、Node、npm 且断网时打开工作台、读取已登记记录和完成模拟实验。核心启动 MUST 不依赖运行时安装或下载依赖。

#### Scenario: 使用私有运行时完成模拟
- **WHEN** 用户在本机打开完整桌面制品，运行环境不提供全局开发工具且运行时不下载或安装依赖
- **THEN** 工作台和私有后台能够启动，模拟会话完成并生成可校验产物

2026-10-06范围调整：核心离线运行和私有依赖要求保留，以本机隔离验证及实际载荷核查为依据。另建干净系统进行断网安装的专项演练已由用户取消，不作为本轮完成前置，也不得据此宣称干净系统已通过。签名和规模化发布验收不在当前范围，组件来源/许可审查仍须完成。

#### Scenario: 内置运行时损坏
- **WHEN** 必需的内置组件缺失、版本不兼容或校验失败
- **THEN** 系统显示具体组件与修复方式，不静默从 PATH 使用任意同名程序或在线安装替代品

### Requirement: 可追溯的依赖制品
系统 SHALL 声明按平台固定的运行环境版本、组件来源、资产散列、依赖锁摘要、适用条件和许可文件。每次实验 SHALL 可追溯实际解析出的工具版本与路径来源。

#### Scenario: 核查工具来源
- **WHEN** 用户查看环境诊断或某次桌面会话的运行环境来源
- **THEN** 能区分内置组件与显式配置的外部工具，并对照固定清单及实际版本

#### Scenario: 有限实验用途的资产核查
- **WHEN** 核查本轮有限实验用途的安装载荷
- **THEN** 组件来源、版本、上游许可声明、已有LICENSE/NOTICE与实际SBOM须可追溯，材料缺项如实记录，默认包不夹带外部SDK/Npcap/驱动或实验数据

2026-10-07范围调整：全面对外分发条件证明、逐库源码缓存和重链接专项不作为本轮任务完成前置；未核对事实继续保留，不被记为全面分发审查通过。SDK按已验证固定版本及doctor/手机实际结果验收，不要求穷尽最小集合。安装资源不写入契约保持，通过正常安装运行及载荷散列核查，不追加人为收紧Windows ACL的专项试验。

### Requirement: 按能力判断依赖就绪
系统 SHALL 分别判断核心、无抓包真机和正式抓包能力，区分缺失、不兼容、权限不足及校验失败。可选硬件工具缺失 MUST 不阻止查看记录与模拟实验，但 MUST 阻止依赖该工具的真实操作。

#### Scenario: 缺少抓包工具
- **WHEN** 主机具有有效 Android 自动化环境但没有可用 Dumpcap
- **THEN** 系统允许无抓包真机验证和核心功能，阻止正式抓包并指出缺项

#### Scenario: Android 版本不兼容
- **WHEN** 手机版本不满足已分发自动化 driver 的最低要求
- **THEN** 系统在发送实验事件前报告不兼容，不以桌面安装成功推定真机可用

### Requirement: 官方准备与授权边界
系统 SHALL 优先复用明确配置的有效 SDK 和系统抓包工具；需要新增组件时展示官方来源、目标目录和所需许可/系统授权步骤。默认发行 MUST 不包含未获分发授权的 Google SDK 或 Npcap，也不得自动接受许可、USB RSA 或系统安全授权。

#### Scenario: 需要准备 SDK
- **WHEN** 主机缺少必需 SDK 组件
- **THEN** 系统提供官方准备流程，等待用户完成所需许可步骤，仅将确认的组件准备到明确目录

#### Scenario: 首次驱动或权限设置
- **WHEN** Windows 需要安装抓包/USB 驱动或 Ubuntu 需要调整 udev/抓包权限
- **THEN** 系统指出管理员准备步骤，桌面应用和后台保持普通用户运行

### Requirement: 不污染用户全局环境
运行环境准备和启动 SHALL 使用应用私有目录或用户明确选择的工具目录，MUST 不修改全局 PATH、默认 Python/Java 或无关 Appium 扩展。各子进程使用一致且可诊断的已解析环境。

#### Scenario: 存在其他版本工具
- **WHEN** 主机 PATH 已有其他 Python、Node、Java 或 Appium
- **THEN** 桌面实验使用声明的私有或明确配置版本，无关工具与设置保持不变

### Requirement: 本次正式预检不能被环境准备替代
系统 MUST 在每次正式采集启动前验证当前手机、网络隔离、目标地址、抓包接口/过滤器、权限和空间。环境工具枚举成功或历史预检通过不得单独证明本次正式采集就绪。

#### Scenario: 准备后网络状态变化
- **WHEN** 环境向导曾通过，但手机随后连接到实验网或接口已失效
- **THEN** 本次正式启动被阻止，显示当前失败原因，不复用旧绿色状态放行
