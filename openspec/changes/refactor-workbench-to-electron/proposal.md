# Proposal

## Why

实验者需要安装后直接使用的本地工作台，而现有浏览器入口仍需自行准备 Python、Node、Appium 等环境，并依赖源码目录管理配置和产物。采用 Electron 承载现有 React 工作台，统一运行环境、后台生命周期和本地证据访问，可以降低部署成本，同时保留已经验证的 Python 实验逻辑。

## What Changes

- 将 Electron 桌面应用设为实验者的主要入口，复用现有工作台的事件编辑、一键启动、运行监控和记录查看；保留浏览器入口与 CLI 作为兼容入口。
- 分发应用私有 Python、独立 Node 和锁定的 Appium/UiAutomator2 运行环境；声明 Java、Android SDK 和抓包工具的安装/授权边界，提供按能力检查与修复指引。应用启动和模拟运行不要求全局 Python、uv、Node、npm 或网络。
- 增加受认证的本机后台启动、健康握手、单实例、进程监督和安全关闭。只管理本实例拥有的 worker/Appium/抓包进程，不接管外部 CLI 实验。
- 分离只读应用资源、用户状态、可编辑配置、实验数据和设备资源锁。桌面应用、CLI 与既有采集脚本共用同一设备锁空间，避免输出目录不同造成互斥失效。
- 以受限 IPC 打开原会话文件和目录，继续提供有大小限制的文本预览；工作区迁移、查看和任务恢复不重写原始证据。
- **BREAKING（内部接口）**：后台根目录解析、进程命令构造和设备锁路径将改为显式运行上下文；保留原 CLI 参数、实验 YAML 和会话产物契约，并提供旧锁/工作区的兼容与诊断路径。

## Capabilities

### New Capabilities

- `electron-workbench`: 桌面入口、现有工作台能力复用、受限 IPC 与原文件操作。
- `managed-runtime-dependencies`: 私有运行环境、依赖清单、离线运行、能力分级预检和平台安装边界。
- `desktop-backend-lifecycle`: 本机后台认证握手、单实例、进程所有权、安全退出和异常恢复。
- `portable-experiment-workspace`: 资源/数据路径分离、配置快照、工作区导入、共享设备锁及原始证据保护。

### Modified Capabilities

无。现有 `parameterized-app-events` 和 `mi-desk-lamp-advanced-controls` 的事件、回执与证据要求继续适用，不因桌面迁移改变。

## Impact

涉及 `automation/` 的 Electron main/preload、React 访问层、Python 路径与运行上下文、服务入口、scheduler/worker、Appium/系统工具解析、资源锁、外部实验发现，以及打包、文档和必要测试。新增桌面构建依赖和版本化运行时清单；首版使用目标为 Windows 11 x64 与 Ubuntu 24.04 LTS x64 的原生桌面，真机/正式采集按平台分别验收；其他平台另建兼容矩阵。保留厂商 App 触发、HA 被动观测及现有 CLI/YAML/产物契约；不迁移 `legacy/` 或重写历史证据。真实实验须按实验规范独立授权和验收。

## 当前交付范围

2026-10-06用户将交付限定为有限实验者使用的应用，明确取消安装器升级/卸载深度检查（8.2）、干净系统断网安装专项验收（8.3）、规模化分发签名与维护/升级回退流程（8.4）、多入口并行完整演练（9.1）。这些取消项不计为完成，也不作为本机功能交付前置。已经实现的安全检查保留，私有依赖和核心离线运行、迁移证据保护、所属进程清理与共享资源锁不降低要求。原生Ubuntu桌面、USB和真实捕获验收继续保留，WSL预验证不替代它们。Windows人工安装交付见automation/desktop/releases/windows-0.1.3；原生Ubuntu未完成条件见tasks.md。

同日用户进一步取消5.5/9.4中的操作系统强制关机、注销或断电专项验收；正常退出、进程崩溃、至少60秒后显式强制停止、所属进程核对和恢复不重跑仍适用。已有Windows/WSL生命周期及桌面、正常抓包停止证据用于关闭修订后的两项，操作系统关机未执行的事实保持未验证，不伪装为验收通过。

2026-10-07按用户要求进一步收敛有限实验用途的验收：保留基础组件来源、版本、上游许可声明、既有通知、SBOM与外部工具边界核对，不要求本轮逐库缓存全部源码、执行重链接专项或证明全面对外分发条件。SDK准备采用实际验证的固定版本清单，不穷尽最小集合；安装资源不写入的契约保留，以正常安装运行和载荷散列核查验收，不追加人为收紧Windows ACL的专项试验。Windows已验证部分与WSL预验证保留，剩余活动验收集中于原生Ubuntu SDK/USB权限、安装运行与正式采集。
